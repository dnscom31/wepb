# 계산교정 7일 UI·UX 기준

적용일: 2026-10-08. 대상: `dnscom31/wepb/mid3-calc-homework`.
현재 원본 코드를 읽고 수정했으며, 이 대화에 과거 참고 이미지는 제공되지 않았습니다.

## 사용 목적

학생은 휴대폰에서 오늘의 계산훈련을 시작하고, 답을 입력하고, 제출 결과와 재도전할 문제를 확인합니다.
교사는 제출 기록에서 미제출·재도전 학생을 먼저 찾고, 첫 제출과 최근 결과를 비교합니다.
화면의 주된 목적은 반복적인 학습·관리 작업입니다.

## 시각 기준

흰 학습지, 옅은 회녹색 바탕, 짙은 잉크색 글자, 녹색 주요 버튼을 사용합니다.
장식·그라데이션·불필요한 애니메이션보다 수식과 상태의 가독성을 우선합니다.

| 역할 | 값 |
|---|---|
| 바탕 `--canvas` | `#F4F6F3` |
| 학습지 `--surface` | `#FFFFFF` |
| 본문 `--ink` | `#172D29` |
| 보조 글자 `--muted` | `#53665F` |
| 구분선 `--line` | `#D6DFD9` |
| 주요 동작 `--accent` | `#0C6557` |
| 주요 동작 hover | `#084F43` |
| 완료 배경 | `#E8F2EC` |
| 재도전 글자 / 배경 | `#8A4B0B` / `#FFF3E2` |
| 글꼴 | Noto Sans KR, Malgun Gothic, sans-serif |
| 버튼·입력 높이 | 46px 이상 / 48px 이상 |
| 입력 글자 | 16px 이상 |
| 큰 영역 모서리 | 14px |
| 간격 기본 | 4·8·12·16·24·32px |

글꼴 CDN 연결이 없으면 로컬 한글 글꼴로 대체됩니다.
CSS 토큰은 `ui.css`, Figma는 같은 색을 변수로 보관합니다.

## 점검 결과와 반영

| 기존 코드에서 확인한 문제 | 반영한 변경 |
|---|---|
| 18문항 전체가 긴 단일 화면 | 6문항씩 3묶음, 이전·다음 이동 |
| 채점 결과가 문제 목록 뒤에 있음 | 별도 결과 화면, 점수·다음 동작 우선 |
| 답 입력 label 숨김 | 각 문항에 보이는 답 label |
| 새 학습 시작 시 오답 필터가 남을 수 있음 | 새 run 초기화 |
| 관리자 조회가 순간 버튼 조건 안에 있음 | 접속 상태 유지, 필터 조작 후에도 결과 표시 |
| 제출 기록 나열만 제공 | Day별 학생 상태, 검색·필터, 첫 점수·최근 점수 |
| 결과 조회 없는 빈 상태 | 시작 안내와 검색 결과 없음 안내 |
| 기본 관리자 PIN이 소스에 공개됨 | 설정된 PIN이 없으면 교사 화면 닫음 |
| 연결이 rerun마다 남음 | DB 작업마다 연결 정리 |
| 답이 비어도 제출 가능 | 미입력 문항 번호 안내 |

## 화면과 반응형

- 시작: 훈련 선택과 주요 시작 버튼, 7일 과정. 넓은 화면은 2열, 작은 화면은 세로.
- 풀이: 수식과 답 입력, 묶음 진행률, 입력 도움말. 문제의 순서를 유지합니다.
- 결과: 정확한 통과 기준(17/18), 결과 요약, 재도전 동작, 문항별 결과.
- 교사: Day 선택, 상태 집계, 검색·필터, 표, CSV. 모바일 표는 가로 스크롤합니다.

선택·완료·재도전은 글자와 색을 함께 사용합니다.
키보드 초점, 입력 label, 동작별 버튼 이름, 모션 감소 설정을 제공합니다.

## 재사용할 개발 지시문

다음 UI 수정 시 PRODUCT.md와 이 DESIGN.md를 먼저 읽습니다.
기존 학습 동작과 채점 규칙을 보존하고, 새 기능은 별도로 명시합니다.
색·글자·간격·상태를 공통 기준에서 사용하고 모바일·키보드·오류·빈 상태를 확인합니다.
화면 리뷰와 기능 테스트를 구분해서 결과를 보고합니다.
새 기능에 대한 효과·정확도·실시간 저장 주장은 검증 없이 표시하지 않습니다.
