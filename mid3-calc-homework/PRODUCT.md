# 제품 맥락

중3 계산 취약 학생에게 7일간 매일 18문항을 제공하는 웹 숙제 도구입니다.
분수·부호 혼합·번분수·제곱근·유리화·혼합·종합 총 126문항을 제공합니다.
현재 버전은 단일 운영자가 사용하는 Streamlit 시험 운영 앱입니다.

학생의 핵심 과업: 훈련 선택 → 6문항씩 답 입력 → 전체 제출 → 결과 → 같은 오답 재도전.
교사의 핵심 과업: PIN 접속 → Day 선택 → 미제출/재도전 확인 → 결과 비교 → CSV 백업.
통과 기준: 90% 이상, 18문항 중 17문항부터 통과.

이번 범위는 UI·UX 개선입니다. 상용 판매 완성을 주장하지 않습니다.
학생 인증·교사별 권한 분리·외부 영구 DB·알림·결제·새 동형문제는 후속 범위입니다.
이름으로 학생을 구분하며 등록된 명부는 없습니다. 완료·미제출은 제출 이력에서 계산합니다.
수식 입력과 채점은 기존 규칙을 유지합니다. 실제 오답 원인은 답만으로 추정하지 않습니다.

언어는 한국어. 학생 안내는 짧고 구체적으로, 실패하면 회복 방법을 함께 안내합니다.
판매 효과나 계산 실력 향상은 아직 검증된 주장이 없습니다.
