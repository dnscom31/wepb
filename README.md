# WEBP → 1000×1000 JPG 스마트 변환기

`.webp` 이미지를 업로드하면 네이버 스마트스토어 대표이미지용 1000×1000 JPG로 자동 변환하는 Streamlit 앱입니다.

## 주요 기능

- WEBP 여러 장 업로드
- 1000×1000 JPG 자동 변환
- 개별 JPG 다운로드
- 전체 ZIP 다운로드
- JPG 품질 조절
- 자동 확대 강도 조절
- 변환 방식 6종 지원

## 변환 방식

### 1. 자동 스마트 크롭

기본값입니다.  
이전 대표이미지 생성기 방향처럼 모델/상품 영역을 감지해서 1000×1000 안에서 더 크게 보이도록 자동 크롭합니다.

### 2. 모델컷 크게

착용컷, 상반신 모델컷처럼 상품이 더 크게 보여야 하는 사진에 사용합니다.

### 3. 상품 전체 보존

마네킹컷이나 상품 전체컷처럼 제품 전체가 잘리면 안 되는 사진에 사용합니다.  
남는 정사각형 영역은 사진 가장자리 픽셀을 늘려 채웁니다.

### 4. 전체 보존

원본이 절대 잘리지 않게 1000×1000 안에 넣고 남는 부분은 배경색으로 채웁니다.

### 5. 꽉 채우기

1000×1000을 빈틈 없이 채우도록 확대 후 중앙 기준으로 자릅니다.

### 6. 가장자리 확장

원본 전체를 살리면서 남는 공간을 사진 가장자리로 채웁니다.
