# WEBP → 1000×1000 JPG 테두리정리 변환기

`.webp` 이미지를 업로드하면 네이버 스마트스토어 대표이미지용 1000×1000 JPG로 변환하는 Streamlit 앱입니다.

## 핵심 방식

이 앱의 기본값은 `테두리 정리 + 가장자리 확장`입니다.

이전 대표이미지 마네킹컷에서 사용했던 방식과 같은 방향입니다.

1. 사진 바깥 테두리/여백을 먼저 조금 잘라냅니다.
2. 옷 전체는 최대한 보존하면서 1000×1000 안에 맞춥니다.
3. 남는 좌우/상하 공간은 사진 가장자리 픽셀을 늘려 채웁니다.

이 방식은 단순 중앙 크롭과 다릅니다.  
중앙 크롭은 옷이 잘릴 수 있지만, 이 방식은 옷 전체를 보존하는 쪽에 가깝습니다.

## 변환 방식

### 테두리 정리 + 가장자리 확장

기본값입니다.  
바깥 여백을 줄이고 남는 정사각형 영역을 사진 가장자리로 채웁니다.

### 가장자리 확장만

테두리를 자르지 않고 원본 전체를 보존한 뒤 남는 영역만 가장자리로 채웁니다.

### 전체 보존

원본 전체를 1000×1000 안에 넣고, 남는 공간은 선택한 배경색으로 채웁니다.

### 테두리 정리 + 전체 보존

바깥 여백을 먼저 줄인 뒤, 남는 공간을 배경색으로 채웁니다.

### 꽉 채우기

1000×1000을 꽉 채우도록 중앙 크롭합니다.  
옷이 잘릴 수 있으므로 의류 상품컷에는 기본 권장하지 않습니다.

## 추천 설정

- 일반 의류 모델컷: 테두리 정리 3~5%
- 마네킹컷/제품컷: 테두리 정리 4~8%
- 옷이 잘리면: 테두리 정리 0~2%
- 여백이 너무 많으면: 테두리 정리 6~10%
